# SmartBite dataset

The meal catalogue is curated from the meal records embedded in the supplied source project and stored separately so the planner can load it as a CSV.

## meals.csv
- diet_type: veg, non-veg or mixed
- meal_name: meal display name
- estimated_cost_inr: estimated cost per serving in INR
- calories_kcal: approximate calories per serving
- protein_g: approximate protein per serving
- ingredients_json: ingredient keys, quantities and optional units

The ingredient price reference is illustrative, not a live market-price feed. Food values vary by recipe, portion size, location and preparation. This is not a clinical nutrition dataset. The planner is rule-based, not a trained ML model. Seek qualified professional advice for medical dietary requirements.
